## About the Project
The Spam Message Detector is a machine learning project that classifies SMS messages as Spam or Normal (Ham). It uses text processing and machine learning techniques to identify unwanted or potentially fraudulent messages.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Matplotlib
- Seaborn
- Gradio

## Methodology
1. Download and load the SMS dataset.
2. Check missing values and duplicate messages.
3. Remove duplicate records.
4. Convert text labels into numerical form.
5. Split the dataset into training and testing sets.
6. Convert text messages into numerical features using TF-IDF.
7. Train the Multinomial Naive Bayes model.
8. Evaluate the model.
9. Use the model to predict whether a message is spam or normal.
10. Create an interactive interface using Gradio.

## Machine Learning Algorithm
Multinomial Naive Bayes is used to classify SMS messages based on the features extracted from their text.

## Dataset
The project uses the SMS Spam Collection dataset containing normal messages and spam messages.

Dataset source: UCI Machine Learning Repository.

## How to Run
1. Install Python.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run all cells sequentially.
5. Enter a message and check whether it is classified as spam or normal.
